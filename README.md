# Calculator

A modern and minimal calculator application built using **Python** and **CustomTkinter** by Anish Sinha.

This calculator features a clean white-grey-black UI, smooth performance, responsive resizing, keyboard & numpad support, and essential mathematical operations.

---

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Percentage Calculation
- Square Root
- Keyboard Support
- Numpad Support
- Responsive Window Resizing
- Modern Minimal UI
- Smooth and Lightweight Performance
- Error Handling

---

## Tech Stack

- Python
- CustomTkinter

## Installation

### Clone the Repository

```bash
git clone https://github.com/anishsinha-dev/Calculator.git
```

---

### Navigate to Project Folder

```bash
cd https://github.com/anishsinha-dev/Calculator
```

---

### Install Required Library

```bash
pip install customtkinter
```

---

## Run the Application

```bash
python calculator.py
```

---

## Keyboard Shortcuts

| Key | Function |

| 0-9 | Numbers |

| / | Division |
